Blitz of Card - x64 Release

기본 실행 방법:
- "Blitz of Card.exe" 또는 "Run-Fullscreen.bat"를 실행합니다.
- 기본 설정은 전체 화면 실행입니다.

문제가 있을 때:
- "Run-Windowed.bat"를 실행합니다.
- 다른 PC에서 전체 화면 문제가 있으면 창 모드로 실행합니다.

중요:
- Windows 기본 터미널 앱을 반드시 Windows Console Host로 설정해야 합니다.
- Windows Terminal에서는 이 프로젝트의 레거시 콘솔 렌더러가 검은 화면으로 보이거나 정상 출력되지 않을 수 있습니다.

Assets 폴더는 삭제하면 안 됩니다.
대상 환경: 64비트 Windows.
